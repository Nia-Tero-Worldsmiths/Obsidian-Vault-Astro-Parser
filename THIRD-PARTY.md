## What this repository actually distributes

Only two third-party things: the Inter font sources under `vendor/fonts/`, and
the Font Awesome icon paths inlined in `NavTree.astro`. Both are permissive and
both are noted below.

Everything else here is original and MIT. That is a consequence of the
repository holding the tool rather than any vault's output — the generated
`src/styles/vault-theme.css` is **not tracked**, so the GPL-2.0 material it
derives from is not distributed from here either. The obligations below still
describe what a *built site* carries, which is why they are documented rather
than deleted: run `extract_theme.py` against a vault and the resulting file is
GPL-2.0 in your working tree, and publishing that site distributes it.

## Not third-party

`src/styles/base.css` is original work and inherits nothing. It exists because
the ITS Theme sets values without attaching them to elements — it defines
`--h1-size` and never binds it to `h1` — so something has to supply that layer.
It was written from measurements of the rendered page rather than derived from
any existing stylesheet, and it is deliberately a separate file from the
generated one so that distinction stays visible in the licence table below.

## How the licences divide

Different licences on different files is ordinary practice, not a workaround.
Nothing here conflicts, because each applies to separate material:

**In this repository** — everything is MIT except two third-party assets:

| Material | Licence |
|---|---|
| Parser and site code (`scripts/`, `src/**/*.astro`, hand-written CSS) | **MIT** — see LICENSE |
| `examples/example-vault/` | **MIT** — a fixture, not worldbuilding |

### Why the images are excluded

They come from more than one source. Most are original illustrations by
Rei-pyo, but some were taken from elsewhere or generated, and those cannot be
licensed by this team at all — a CC grant over them would be granting rights
nobody here holds, which is worse than granting nothing, because it invites
third parties to reuse the work on our authority.

So no image is licensed until its origin is settled. `z_Assets/CREDITS.yaml` in
the vault records each file's origin and author as they are confirmed. Two
things follow from that being the source of truth:

- Rei-pyo's illustrations are **all rights reserved** for now. That is not a
  decision against licensing them, only the absence of one — and it is the
  reversible direction. A CC licence cannot be withdrawn once granted, so
  reserved-then-opened is safe while opened-then-reserved is not.
- Anything whose origin is external stays out of the published site entirely,
  not merely out of the licence.

`base.css` is deliberately a separate file rather than part of the generated
one. It is original work and inherits nothing; folding it into `vault-theme.css`
would put it inside a GPL-2.0 file for no reason.
