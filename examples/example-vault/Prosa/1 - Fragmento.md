# Fragmento

Prose notes carry the `prosa` cssclass, which `custom.css` uses to justify the
text and widen tables. This one exists so that layout has a page to appear on.

The harbour smelled of tar and cold iron, and the ships came in regardless.

---

A horizontal rule above, because the theme draws it as an ornament rather than
a line and that is worth being able to see.

Nothing here links anywhere. A note with no outgoing links is the case the
graph module has to survive.
